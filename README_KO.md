# 강의 자동 녹화 프로그램

첨부한 화면의 `.course_timeline.accordion`, `li.section`, `li.unit_line`, `unitXXXX`, iframe 내부 `video#main-video`와 Plyr 재생 버튼을 기준으로 만든 Windows용 Python 프로그램입니다.

왼쪽 목차를 읽어서 대목차 순서대로 소목차를 클릭하고, 영상을 0초로 되돌린 뒤 OBS 녹화를 시작합니다. 정상 재생 종료를 확인하면 OBS를 종료하고 대목차 폴더에 강의 제목으로 파일을 저장합니다. 사이트의 수강 완료 표시와 관계없이 모든 강의를 기본 선택합니다.

## 1. 처음 설치하기

1. ZIP을 **완전히 압축 해제**합니다. 예: `C:\LectureRecorder`.
2. [Python](https://www.python.org/downloads/windows/) 3.10 이상을 설치합니다. 3.12를 권장합니다. 설치 창에서 **Add python.exe to PATH**를 선택합니다.
3. [OBS Studio](https://obsproject.com/download)를 설치하고 실행합니다. **OBS 28 이상 / WebSocket 5**를 사용합니다.
4. `설치.bat`를 더블클릭합니다. Python 패키지와 예비 Chromium을 설치합니다. 이미 설치된 Chrome이나 Edge를 기본적으로 사용할 수 있습니다.
5. OBS에서 **도구 → WebSocket 서버 설정 → WebSocket 서버 활성화**를 켭니다. 포트 `4455`와 서버 비밀번호를 확인합니다. OBS 자동 구성 마법사가 표시되면 **녹화용**으로 설정합니다.
6. MP4가 필요하면 OBS **설정 → 출력 → 녹화 형식**에서 **하이브리드 MP4 또는 MP4**를 선택합니다. OBS가 MKV로 설정되어 있으면 MKV로 저장됩니다. 프로그램이 확장자만 MP4로 바꾸는 일은 없습니다.

프로그램은 설치된 Python을 사용하므로 독립 실행 EXE가 아닙니다. 관리자 권한은 필요하지 않습니다.

## 2. 실행하기

1. `실행.bat`를 더블클릭합니다.
2. 실제 강의 페이지의 주소창에서 복사한 **강의 주소**를 입력합니다. 스크린샷에 실제 주소가 없어 기본값은 비워 두었습니다. 영상 iframe 주소를 입력하지 마세요.
3. 저장 폴더와 OBS 비밀번호를 입력하고 **OBS 연결 테스트**를 누릅니다.
4. **1. 브라우저 열기**를 누릅니다. 열린 전용 브라우저에서 직접 로그인하고 왼쪽 목차가 보이는 강의 화면까지 들어갑니다. 로그인 정보는 이 프로그램의 전용 브라우저에 유지됩니다.
5. **2. 강의 목록 읽기**를 누릅니다. 대목차와 강의 목록을 확인합니다. 행 클릭 또는 Space로 강의를 선택/해제할 수 있고, 대목차 행을 클릭하면 그 안의 강의를 한꺼번에 선택합니다.
6. 처음에는 **짧은 강의 하나만 선택**하고 **3. 선택 강의 녹화**를 누릅니다. 저장된 영상의 화면과 소리를 확인한 다음 전체 선택으로 실행하세요.

목록이 펼쳐져 있지 않아도 숨겨진 강의 제목을 읽습니다. 아래쪽 소목차는 자동 스크롤하며, 완료된 강의도 처음부터 재생합니다. 녹화가 시작되면 설정 창은 최소화되고 종료 시 다시 나타납니다. **중지**를 누르면 현재 영상을 멈추고 미완료 파일을 보관합니다. 창의 X 버튼도 OBS와 브라우저를 정리한 후 종료합니다.

사이트가 왼쪽 목차를 접어도 숨겨진 항목을 직접 선택합니다. 선택한 항목이 동영상이 아닌 텍스트·이미지 등의 읽기 자료이면 잠시 확인한 뒤 **자료 · 건너뜀**으로 기록하고 다음 선택 강의로 계속 진행합니다.

브라우저를 먼저 닫으면 자동화가 중단됩니다. 녹화 중에는 해당 브라우저의 영상, 목차, 재생 속도와 OBS 녹화 버튼을 직접 조작하지 마세요. Windows 절전은 실행 중에만 막지만, 수동 화면 잠금이나 노트북 덮개 닫기까지 막지는 않습니다.

## 3. OBS 자동 구성과 소리

**OBS 화면·PC 소리 자동 구성**을 켜면 녹화용 임시 장면을 만들고 기본 모니터와 Windows 기본 출력 장치의 소리를 캡처합니다. OBS의 기존 글로벌 데스크톱 오디오와 마이크는 이 실행 동안 음소거하여 소리가 겹치지 않게 합니다. 끝나면 기존 장면과 음소거 상태를 복원하고 임시 소스를 삭제합니다. 설정을 복원하지 못한 경우 다음 녹화 연결에서 다시 복원합니다.

자동 구성은 모니터 전체와 그 PC의 출력 소리를 녹화합니다. 다른 창이 브라우저 위를 덮거나 다른 앱이 소리를 내면 함께 들어갑니다. 듀얼 모니터를 사용하거나 강의 소리를 별도 출력 장치로 보내는 경우에는 OBS에서 캡처할 장면을 직접 구성하고 **자동 구성** 옵션을 끄세요. 이때는 선택되어 있는 OBS 장면을 그대로 사용합니다. 영상 전체 화면 옵션은 사이트의 Plyr 전체 화면 버튼을 사용하며 사용할 수 없으면 브라우저 화면으로 진행합니다.

**녹화 없이 영상 이동 테스트**는 OBS 없이 목차 이동과 영상 종료 감지만 확인합니다. 테스트 결과는 녹화 완료로 저장하지 않습니다.

## 4. 저장 형식과 이어서 녹화

파일은 아래와 같은 구조로 저장됩니다. 대목차 번호, 제목, 고유 강의 ID가 포함되고 기존 파일이 있으면 `__take02` 등을 붙입니다.

```text
recordings/
  course_<강의별 고유키>/
    course_catalog.json
    progress.json
    01_딥러닝이론/
      001_딥러닝을 배우면 이런 것들이 가능__unit4553.mp4
      002_Tensorflow 2 개발환경 세팅__unit4182.mp4
    02_Project 1 .../
      001_이젠 Keras로 ...__unit4325.mp4
    diagnostics/
      <실패한 강의의 화면 캡처>.png
logs/
  <실행 날짜>.log
browser_profile/
  <전용 브라우저 로그인 상태>
runtime/
  <동시 실행 방지 및 OBS 설정 복원 기록>
```

- 실제 확장자는 OBS 설정에 따릅니다.
- **완료 파일 확인 후 이어서 녹화**를 켜면 `progress.json`의 완료 상태, 파일 존재 여부, 기록된 파일 크기가 일치하는 강의만 건너뜁니다. 사이트의 빨간 수강 완료 체크는 건너뛰기 기준으로 사용하지 않습니다.
- 중지하거나 재생에 실패한 파일은 `__INCOMPLETE`가 붙고 다음 실행에서 강의 처음부터 다시 녹화합니다. 부분 파일을 이어 붙이지 않습니다.
- 처음부터 다시 녹화하려면 이어서 녹화 옵션을 끄거나 새 저장 폴더를 선택합니다. 기존 영상은 덮어쓰지 않습니다.
- 기본적으로 강의당 한 번 재시도합니다. 그래도 실패하면 중단합니다. **실패한 강의는 다음으로 이동**을 켜면 영상 오류는 넘어가고, OBS 연결/녹화/파일 저장 오류는 전체 실행을 중단합니다.
- 영상이 60초 동안 진행되지 않으면 실패 처리합니다. 재생 위치가 끝까지 도달하기 전에 남은 시간을 잘라서 다음 강의로 넘어가지 않습니다.

## 5. MKV를 MP4로 자동 변환하기 (선택)

OBS를 MP4로 설정하면 추가 도구 없이 MP4가 저장됩니다. MKV 등으로 녹화하고 MP4를 함께 만들려면 [FFmpeg](https://ffmpeg.org/download.html)를 설치하고 Windows PATH에 추가하거나 `config.json`의 `ffmpeg_path`에 `ffmpeg.exe` 전체 경로를 지정하세요. `MP4 변환` 옵션을 켜면 재인코딩 없이 컨테이너를 변환합니다. 성공해도 원본 MKV는 함께 보관됩니다. 변환에 실패하면 원본을 완료 파일로 유지합니다. 원본과 MP4를 함께 저장할 공간이 필요합니다.

## 6. 자주 확인할 문제

| 증상 | 확인할 내용 |
| --- | --- |
| 브라우저가 열리지 않음 | 설치.bat를 다시 실행하고 Chrome/Edge 설치 여부 확인. 실행 중인 이 프로그램을 중복으로 열지 않기. |
| `This Course can not be taken` XML 화면 | 전용 브라우저가 아직 로그인되지 않은 상태입니다. 사이트 첫 화면으로 이동해 로그인한 뒤 강의 주소로 다시 들어가기. |
| 강의 목록이 없음 | 전용 브라우저에 로그인하고 왼쪽 목차가 나타난 후 목록 읽기. 사이트 디자인이 바뀌었으면 selector 확인. |
| 텍스트 자료에서 멈춤 | v1.1 이상은 영상이 없는 자료형 항목을 자동으로 건너뜁니다. 이전 상태가 남으면 강의 목록을 다시 읽고 실행. |
| 새 플레이어 전환 확인 실패 | 강의 클릭 후 실제 영상이 바뀌는지 확인. 접근 기간 만료, 서버 오류, 추가 팝업 여부 확인. |
| video#main-video를 찾지 못함 | 사이트가 다른 플레이어를 사용하는 경우 `config.json`의 video_selector 수정. 접근 제한은 프로그램이 해제하지 않음. |
| OBS 연결 실패 | OBS 실행, WebSocket 활성화, 포트 4455, 비밀번호 확인. 다른 OBS 녹화는 먼저 종료. |
| 영상에 화면/소리가 없음 | 짧은 강의로 캡처 모니터와 기본 소리 장치 확인. 수동 OBS 장면을 사용 중이면 화면·소리 소스가 활성화되어 있는지 확인. |
| 저장 공간 오류 | 저장 폴더와 OBS 원래 녹화 폴더 모두 여유 공간 확인. 기본 최소 여유 공간은 1 GB. |
| MP4가 아니라 MKV로 저장됨 | OBS 녹화 형식을 MP4로 설정하거나 FFmpeg 자동 변환 사용. |
| 프로그램 강제 종료 후 OBS 설정이 남음 | 같은 OBS 포트로 다시 녹화 연결하면 복원 기록을 적용. 진행 중인 다른 녹화/방송이 있으면 먼저 종료. |

OBS 응답이 끊겨 파일 경로를 받지 못한 경우 원래 OBS 녹화 폴더의 파일을 확인하세요. 프로그램은 가장 최근 파일을 임의로 선택하거나 다른 녹화 파일을 이동하지 않습니다.

## 7. 개발자용 실행

`config.example.json`을 `config.json`으로 복사하면 GUI 없이도 설정할 수 있습니다. Windows GUI에서 기억한 OBS 비밀번호는 Windows 사용자 계정에 묶어 암호화하여 저장합니다. 콘솔에서는 `OBS_PASSWORD` 환경 변수를 사용할 수 있습니다. 로그인 비밀번호를 코드에 적을 필요는 없습니다.

```powershell
.\.venv\Scripts\python.exe app.py --cli --url "실제 강의 주소" --limit 1
.\.venv\Scripts\python.exe app.py --cli --playback-only --url "실제 강의 주소" --limit 2
.\.venv\Scripts\python.exe app.py --check-obs
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

`--yes`는 콘솔에서 목록 확인 Enter만 생략합니다. 사이트 첫 로그인은 브라우저에서 직접 수행합니다. 테스트는 자체 페이지와 모의 OBS 서버를 사용하며 실제 강의에 접근하지 않습니다. 실제 사이트 계정, 실제 Windows OBS 캡처와 음성 결과는 사용자의 PC에서 첫 강의로 확인해야 합니다. 녹화 가능한 강의와 이용 범위에 맞게 사용하세요.

구현 참고: [Playwright Python Frames](https://playwright.dev/python/docs/frames), [Persistent Browser Context](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context), [OBS 원격 제어 안내](https://obsproject.com/kb/remote-control-guide), [OBS WebSocket 5 프로토콜](https://github.com/obsproject/obs-websocket/blob/master/docs/generated/protocol.md).
