LECTURE RECORDER · WINDOWS

목차 순서대로,
강의별 파일로 저장하기

첨부한 강의 화면의 목차와 Plyr 영상 구조에 맞춘 Python 프로그램입니다.
강의를 선택하면 영상 준비, OBS 녹화, 파일 정리를 자동으로 진행합니다. 목차가 접혀도 다음 항목을 선택하며, 영상이 없는 읽기 자료는 자동으로 건너뜁니다.

처음 한 번 설치

  1. ZIP을 완전히 압축 해제하세요. 짧은 경로 C:\LectureRecorder를 권장합니다.
  2. Python 3.10 이상과 OBS Studio 28 이상을 설치하세요. Python 설치 시 Add python.exe to PATH를 선택합니다.
  3. 설치.bat를 더블클릭합니다. 필요한 Python 패키지와 예비 브라우저를 설치합니다.
  4. OBS를 실행하고 도구 → WebSocket 서버 설정에서 서버를 활성화합니다. 포트 4455와 서버 비밀번호를 확인하세요.
  5. MP4로 저장하려면 OBS 설정 → 출력 → 녹화 형식에서 하이브리드 MP4 또는 MP4를 선택하세요.

프로그램 실행

  1. 실행.bat를 열고 실제 강의 주소, 저장 폴더, OBS 비밀번호를 입력합니다. OBS 연결 테스트로 연결을 확인하세요.
  2. 1. 브라우저 열기를 누릅니다. 열린 전용 브라우저에서 직접 로그인한 뒤 왼쪽 목차가 보이는 화면으로 이동하세요.
  3. 2. 강의 목록 읽기를 누르고 녹화할 강의를 선택합니다. 대목차를 누르면 소목차를 한꺼번에 선택할 수 있습니다.
  4. 3. 선택 강의 녹화를 누릅니다. 녹화 중 설정 창은 최소화됩니다. 전체 처리가 끝나면 다시 나타납니다.
먼저 짧은 강의 하나를 녹화해 화면과 소리를 확인하세요.
파일이 정상이라면 전체 선택으로 실행하면 됩니다. 사이트 주소는 스크린샷에 없어 직접 입력하도록 비워 두었습니다.

이어서는 어떻게?

완료 파일 확인 후 이어서 녹화를 켜면 실제 파일이 있는 완료 강의만 건너뜁니다. 사이트 수강 완료 체크는 모두 무시하고 녹화 대상에 포함합니다.

중지한 강의는 __INCOMPLETE 파일로 보관하고 다음 실행에서 0초부터 다시 녹화합니다.

OBS 자동 구성

자동 구성 옵션은 기본 모니터와 기본 PC 소리를 녹화합니다. 마이크는 제외하며 종료 후 기존 OBS 장면과 음소거 상태를 복원합니다.

듀얼 모니터나 별도 오디오 장치는 OBS에서 직접 장면을 구성하고 자동 구성 옵션을 꺼서 사용하세요.

파일과 도움말

녹화 파일은 recordings 아래 대목차별로 저장됩니다. 파일명에는 강의 순번, 제목, 고유 ID가 들어갑니다. 기존 파일은 덮어쓰지 않습니다.

OBS가 MKV로 설정되어 있으면 MKV로 저장합니다. FFmpeg가 있으면 MP4를 함께 만들 수 있고 원본도 보관합니다. 상세 설정과 문제 해결은 같은 폴더의 README_KO.md를 확인하세요.

코드와 설치 스크립트를 모두 포함한 Python 프로그램이며 독립 실행 EXE는 아닙니다. 모의 강의 페이지와 모의 OBS 서버로 핵심 동작을 검증했습니다. 실제 계정 로그인, Windows 캡처 장치와 녹화 소리는 사용자의 PC에서 확인해야 합니다.

녹화 중에는 해당 브라우저와 OBS 녹화 버튼을 직접 조작하지 말고, 종료할 때 프로그램의 중지 버튼을 사용하세요.
